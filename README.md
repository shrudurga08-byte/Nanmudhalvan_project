# ⚖️ LegalEase - AI Legal Document Generator

LegalEase is an AI-powered web app that helps users create, edit and save legal documents in minutes. The user fills in a few details, Gemini drafts the document, and everything is stored in a local database.

## Setup Instructions

### 1. Create the Environment

Windows (PowerShell):


python -m venv venv
.\venv\Scripts\Activate.ps1


macOS / Linux:


python3 -m venv venv
source venv/bin/activate


---

### 2. Install Dependencies


pip install -r requirements.txt


---

### 3. Configure the API Key

Windows:


copy .env.example .env


macOS / Linux:


cp .env.example .env


Open `.env` and set your key (get one at https://aistudio.google.com/apikey):


GEMINI_API_KEY=your_key_here


---

### 4. Generate Placeholder Logos (Optional)


python create_logo.py


---

### 5. Run the Project

Terminal 1 (Backend):


uvicorn legalEaseAPI.main:app --reload


Terminal 2 (Frontend):


streamlit run frontend/app.py


Or simply run `run.bat` (Windows) / `./run.sh` (macOS / Linux).

---

### 6. Open in Browser

- App: http://localhost:8501
- API Docs: http://localhost:8000/docs

The SQLite file `legalease.db` is created automatically on first start.

## Tech Stack

- **Frontend:** Streamlit
- **Backend:** FastAPI + Uvicorn
- **AI Model:** Google Gemini
- **Database:** SQLite (SQLAlchemy)
- **Document Export:** python-docx, fpdf2

---

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/generate` | Create and save a document |
| GET | `/documents` | List saved documents |
| GET | `/documents/{id}` | Fetch one document |
| PUT | `/documents/{id}` | Update edited content |
| DELETE | `/documents/{id}` | Delete a document |

---

## How It Works

1. User selects a document type and enters the details
2. Frontend sends the request to the FastAPI backend
3. Backend builds a prompt and calls the Gemini model
4. Generated document is saved in the SQLite database
5. Output is shown in the app, where it can be edited, saved or deleted ✅

---

## Deployment

- **Backend** (Render / Railway / Fly.io):

  ```
  uvicorn legalEaseAPI.main:app --host 0.0.0.0 --port $PORT
  ```

- **Frontend** (Streamlit Community Cloud): set `API_URL` to the deployed backend URL.

On hosts with ephemeral disks, set `DATABASE_URL` to a hosted Postgres database and run `pip install psycopg2-binary`.
